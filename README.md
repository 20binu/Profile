# Binu R. — Academic Portfolio

A responsive personal academic portfolio website built with **HTML, CSS and vanilla JavaScript**.

## Repository structure

```text
binu-academic-portfolio/
├── assets/
│   └── profile.jpg
├── index.html
├── style.css
├── script.js
├── README.md
└── .gitignore
```

## Run locally

No build tools or dependencies are required.

1. Download or clone this repository.
2. Keep `assets/profile.jpg` in the `assets` folder.
3. Open `index.html` in a modern web browser.

For a local development server, you can use the VS Code Live Server extension.

## Deploy

This is a static website and can be hosted using GitHub Pages or any static web hosting provider.

### GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.

## Customize

- Edit the profile, education, experience and publication content in `index.html`.
- Replace `assets/profile.jpg` with an updated portrait, keeping the same filename or updating the image path in `index.html`.
- Change colours, typography and layout in `style.css`.
- Change navigation, publication filters and scroll effects in `script.js`.

## Content notes

- Website content is based on the supplied CV.
- Personal date of birth, gender and residential address are not included in the public-facing website.
- The professional email displayed is `binur@rajagiritech.edu.in`.
- The CV repeats one journal article; it is listed once in the website.
- ORCID and LinkedIn were mentioned in the CV without profile URLs, so no links have been fabricated.
- Please verify publication metadata, titles, indexing labels and ISBN details before publishing.
